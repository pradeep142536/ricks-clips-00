# Main Video — Emu War

This is the clean project folder for the new video.

- All new story, script, characters, world files, previews, voices, and renders stay here.
- The old `episodes/emu-war` render is not an input to the new video.
- The connected 3D world is built before the final shot render.
- A world preview and short animatic must be checked before the full GPU render.
- The final render must use the new script and new voice, not the previous Boston/Molasses assets.

## Build order

1. Story and narration
2. Character reference and expressions
3. Connected 3D world
4. World inspection preview
5. Storyboard and short animatic
6. User approval
7. Full Colab GPU render
