# Connected World Gate

`world_map.json` is the source of truth for the Emu War environment. All future Three.js locations must use its metre coordinates; no shot may use an independent floating set.

Required approval evidence before animation:

1. `world_map.png`
2. `scale_test.png` with a 1.7 m soldier, 1.9 m emu and 5 m truck
3. `world_flythrough.mp4` travelling continuously across the map
4. `continuity_contact_sheet.png` checking repeat landmarks from each used camera
