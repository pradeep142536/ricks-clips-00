# Rick's Clips Cloud Renderer (GitHub Actions)

This repository automatically renders the full 83.5-second Rick's Clips animated video (**The 1980 Lake Peigneur Disaster: The Day A 14-Inch Drill Swallowed An Entire Lake**) in 1080x1920 9:16 vertical resolution using free cloud compute.

## How to Run:
1. Push this repository to your GitHub account (public or private).
2. Go to the **Actions** tab on your GitHub repository page.
3. Click **Render Full Episode** in the left sidebar.
4. Click **Run workflow** -> **Run workflow**.
5. You can now close your browser and turn off your computer!
6. When the workflow finishes (~15-20 minutes), click the completed run and download **`final_full_episode_1080p`** under **Artifacts**!
